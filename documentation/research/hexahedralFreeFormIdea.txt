Technical Report: Reduced-Order Elastodynamic Simulation using Voxel-Based Hexahedral Cages and 
FreeForm Skinning Eigenmodes1. IntroductionHigh-fidelity elastodynamic simulation remains a 
foundational challenge in computer graphics, virtual reality, and physical AI. While traditional 
Finite Element Methods (FEM) serve as the gold standard for accuracy, their reliance on dense 
volumetric tetrahedral meshes introduces staggering computational costs and structural 
vulnerabilities under high degrees of freedom (DoFs). Conversely, modern mesh-free subspace 
solvers—such as Simplicits and FreeForm—dramatically accelerate runtimes by simulating physics in a 
low-dimensional weight space via Linear Blend Skinning (LBS).This report presents a novel 
engineering pipeline that marries structural geometric preprocessing with subspace mechanics. By 
scanning a high-resolution mesh into voxels, structuring it into a hexahedral mesh cage, and 
executing FreeForm’s Reproducing Kernel Particle Method (RKPM) eigenanalysis over the cage nodes, 
we establish an ultra-fast setup pipeline. The resulting optimized skinning weights are smoothly 
interpolated back to the high-resolution asset, ensuring real-time, physically plausible 
deformations.2. Conceptual Workflow & Architectural PipelineThe proposed architecture operates in 
three distinct phases: geometric discretization, subspace eigenanalysis, and runtime 
deformation.[High-Res Mesh] ➔ [Voxelization] ➔ [Hexahedral Cage]

Phase 1: Spatial Discretization (Voxelization to Hexahedral Cage)Voxel Ingestion: The arbitrary 
high-resolution surface mesh is converted into a structured voxel grid using an inside/outside 
distance query or signed distance field (SDF).Cage Generation: The boundary and interior voxels are 
converted into a structured hexahedral mesh cage. The cell corners (vertices) or cell barycenters 
of this hexahedral cage are designated as the fixed particle nodes (\(p_{k}\)) for the simulation 
space.Phase 2: Subspace Weight Generation (FreeForm Setup)Kernel Construction: Rather than 
utilizing irregular spatial point distributions, the structured hexahedral grid provides an 
optimized layout for defining the Reproducing Kernel Particle Method (RKPM) basis. The kernel 
radius (\(r\)) for each node is naturally parameterized by the uniform cell dimensions.Hessian 
Formulation: FreeForm builds the weight-space Hessian matrix (\(H_{w}\)) directly over the 
hexahedral grid. For homogeneous materials, this simplifies cleanly to a weak-form Laplace matrix 
(\(L\)) proportional to the Dirichlet energy:\((\mathbf{H}_{w})_{ij}=(\lambda +4\mu )\int _{\Omega 
}\nabla \phi _{i}(\mathbf{X})^{T}\nabla \phi _{j}(\mathbf{X})d\mathbf{X}\)Eigenanalysis: Rather 
than wasting minutes on gradient-based neural network optimizations (as required by Simplicits), 
FreeForm computes a generalized eigenvalue problem using highly efficient linear algebra 
routines:\(\mathbf{H}_{w}\mathbf{v}=\lambda \mathcal{M}\mathbf{v}\)The first \(m\) generalized 
eigenvectors are extracted instantly (~3 seconds), defining the optimal, mathematically orthogonal 
skinning weights (\(W\)) at each cage node.Phase 3: Interpolation and Runtime SimulationWeight 
Mapping: The continuous nature of FreeForm’s RKPM shape functions allows the system to seamlessly 
evaluate the exact skinning weight for any coordinate (\(X\)) belonging to the original 
high-resolution surface mesh. Alternatively, standard trilinear shape functions of the hexahedral 
cells can map cage weights back to the high-res vertices.Subspace Dynamics: At runtime, the 
simulation executes solely on the low-dimensional degrees of freedom (DoFs) of the cage via 
implicit backward Euler time stepping. The dense, high-resolution mesh is updated in parallel on 
the GPU using standard Linear Blend Skinning (LBS).3. Key Technical AdvantagesCombining FreeForm's 
mathematical framework with a structured hexahedral cage yields unique benefits over existing 
pipelines:Elimination of "Neural Smoothing" Errors: Neural fields (like Simplicits) tend to 
over-smooth local deformations due to inductive biases in coordinate MLPs. FreeForm’s explicit RKPM 
formulation captures distinct material gradients cleanly.Trivial Volume Integration: Computing mass 
matrices (\(\mathcal{M}\)) and stiffness tensors over arbitrary point clouds requires complex 
spatial bucketing. A structured hexahedral cage provides regular, uniform geometric domains, making 
Monte Carlo or Gauss-quadrature volume integration perfectly uniform and hyper-fast.Exact 
Orthogonality and Numerical Stability: FreeForm enforces strict mathematical orthogonality up to 
numerical precision during the eigendecomposition. This provides a highly conditioned system 
Hessian during Newton-Raphson time-stepping, drastically reducing runtime solver divergence 
compared to the soft-penalty constraints used by neural solvers.Drastic Reduction in Setup 
Overhead: Standard subspace precomputations often demand hours of offline data generation. The 
proposed pipeline builds an expressive, material-aware deformation basis within seconds, turning a 
historically offline precomputation phase into an interactive setup utility.4. Implementation 
Guidelines & Software StackTo engineer this pipeline within production graphics loops, the 
following software components are recommended:Voxelization & Cage Synthesis: OpenVDB or Blender’s 
Geometry Nodes can instantly voxelize complex boundaries and reconstruct watertight hexahedral 
grids from high-resolution geometry.Subspace Matrix Assembly: Implement the RKPM shape function 
evaluations and Hessian matrix assembly within NVIDIA Warp. Warp's Python-wrapped native C++/CUDA 
kernel compiler maximizes memory throughput on the GPU.Eigendecomposition: Execute the generalized 
eigenvalue problem natively on the GPU using PyTorch's specialized sparse solver block 
(torch.lobpcg), ensuring that double-precision matrices remain entirely in VRAM.
